    <h2>About</h2>
    <p>
      This project is a feature-rich online grocery shopping platform designed to provide users with a seamless and efficient shopping experience. Users can browse products, view details, manage a shopping cart, and proceed to checkout.
    </p>

    <h2>Getting Started</h2>
    <p>This project was built using React and bootstrapped with Create React App.</p>

    <h3>Available Scripts</h3>
    <ul>
      <li>
        <code>npm start</code>: Runs the app in development mode. Open <a href="http://localhost:3000" target="_blank">http://localhost:3000</a> to view it in the browser.
      </li>
      <li>
        <code>npm test</code>: Launches the test runner in interactive watch mode.
      </li>
      <li>
        <code>npm run build</code>: Builds the app for production to the <code>build</code> folder.
      </li>
      <li>
        <code>npm run eject</code>: Exposes the configuration files and dependencies. This is a one-way operation.
      </li>
    </ul>

    <h2>Features</h2>
    <ul>
      <li>Browse products by category</li>
      <li>Detailed product pages</li>
      <li>Shopping cart management</li>
      <li>Special offers and promotions</li>
      <li>Contact page for user support</li>
    </ul>

    <h2>Technologies Used</h2>
    <ul>
      <li>Frontend: React, Tailwind CSS</li>
      <li>Routing: React Router</li>
      <li>State Management: React Context and Reducers</li>
    </ul>

    <h2>Installation</h2>
    <ol>
      <li>Clone the repository: <code>git clone https://github.com/your-username/online-grocery-shop.git</code></li>
      <li>Navigate to the project directory: <code>cd online-grocery-shop</code></li>
      <li>Install dependencies: <code>npm install</code></li>
      <li>Start the application: <code>npm start</code></li>
    </ol>
